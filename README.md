+++++++++  Game Development Training Projects :  +++++

Overview

-------->  This repository showcases the projects developed during a 4-month professional training program at Geeks Institute, focused on video game development using Unity and C#. The purpose of this repository is to demonstrate the learning process, practical exercises, and applied skills acquired throughout the training.

Training Objectives

-------->  During this training, the main objectives were to:

           . Understand the fundamentals of video game development

           . Learn to use the Unity game engine efficiently

           . Develop games using C# scripting

           . Design and implement gameplay mechanics

           . Build both 2D and 3D game experiences

-------> Technologies & Tools:

           . Game Engine: Unity

           . Programming Language: C#

           . Game Types: 2D and 3D

           . Version Control: Git & GitHub

--------> Skills & Concepts Learned:

--> Throughout the training, the following concepts and skills were covered:

          . Unity Editor fundamentals

          . GameObject and Component system

          . C# scripting for games

          . Player movement and controls

          . Physics and collision handling

          . Animations and Animator Controller

          . Camera systems

          . Input system

          . Game states and scene management

          . Gameplay mechanics design

          . Basic UI elements (menus, HUD)

          . Audio integration (sound effects & music)

          . Debugging and optimization basics
