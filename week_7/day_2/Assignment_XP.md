**Mini Project Documentation**



**Step 1 — Project Overview**



* Project Name: Bouncing Ball
* Genre: Arcade / Platformer
* Platform: PC
* Team Size: 1 developer
* Duration: 2 days
* Project Goal: Create a simple game where the player controls a ball and avoids obstacles while moving upward.



**Step 2 — Development Report**



* The project was developed using Unity
* I used basic physics to control the ball movement
* Development was done step by step, starting with movement, then obstacles, and basic UI.



**Step 3 — Problems Encountered**



1. The ball movement was hard to control
2. The difficulty increased too fast
3. Some collisions did not work correctly



**Step 4 — Solutions / Adjustments**



1. Adjusted physics values like speed and bounce.
2. Reduced obstacle speed in early levels.
3. Fixed collision layers and tags.



**Step 5 — Key Learning**



Testing gameplay early helps find problems faster and improves player experience
